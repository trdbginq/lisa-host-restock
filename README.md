## 为什么丽萨主机总在补货

把缺货理解成「商家没货」不准确。丽萨卖的核心资源是 IP，尤其是双 ISP 住宅 IP，这类地址由真实家庭宽带运营商分配，一个段就那么多，用完只能等上游放新段。这是它频繁补货的第一个原因。

第二个原因是单台宿主机的容量。套餐是按宿主机切分的，一台机器卖满就得等新机器上线。美国 9929 线路上新就是这个逻辑：全新宿主机加 NTT 216.167 新 C 段双 ISP 原生住宅 IP，KVM + NVMe，最低配 1 核 1G / 1TB 流量 / 50Mbps，原价 68 元/月，用码 TS-CBP205DQJE 九折后约 61.2 元/月。这就是一次典型的「补货」动作，新机器加新号段一起放出来。

第三个原因是上游运营商调整，这类缺货最不可控。英国机房近期就因为上游运营商原因更换了部分 IP 段，目前正在切换为英国天空电讯 Sky 的双 ISP 住宅家宽 IP，受影响用户会获得补偿时长。这种整段下架跟卖光不是一回事，补货时间取决于运营商，商家也给不出准确日期。买英国款之前，先去 Telegram 频道确认当前段位状态，比看下单页靠谱。

还有一个常被忽略的细节：美国 38 段和 154 段的产品目前中国移动去程方向有拥堵，电信联通正常，70 段和 64 段不受影响。移动用户如果买到 38/154 段，可以工单要求换段。这不算缺货，但会影响体验，值得提前知道。

## 几个必须先知道的限制

**48 小时退款有四个例外。** 计时从服务开通那一刻开始，机器自动开通，等于你拿到 IP 就开始倒计时，不是从付款算。条款原文写明 heavily used services are not eligible，「重度使用」没有量化标准，争议时以客服判断为准。试用套餐明确无退款，比如 2 元 1 天的 CN2 GIA 试用。VDS 类家宽静态住宅产品只退网站余额，包括加州、西雅图、日本 ISP、日本 IIJ、德国双 ISP 这些年付 VDS。超过 48 小时窗口中途退出，只能按比例退到账户余额，不退现金。

**非大陆优化的机型别指望直连速度。** 新加坡、台湾、英国都属于这一类，官方建议经香港或日本中转。如果你的业务全靠国内直连访问，这几款再便宜也不适合。

**不限流量有端口限速和公平使用规则。** 9929 的不限量 Lite 是 20Mbps、Pro 是 50Mbps，香港 CMI 不限量是 30/50Mbps。不限流量不等于不限速，持续跑满带宽可能触发公平使用条款。

**美国 38 段和 154 段移动去程拥堵。** 电信联通不受影响，70 段和 64 段正常。移动用户下单前可以问清段位，或者开好工单换段。

**美国 9929 豪华版的价格存在两种记录。** 4核4G/80G/8TB/100Mbps 这一档，一处记录是 388 元/月，另一处是 899 元/月，无法交叉确认。买这一档请直接看下单页金额，别拿二手文章的价格去核对。
